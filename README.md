# EcoleDirectHA

Dépôt d'add-on Home Assistant : envoie les devoirs et notes EcoleDirecte sur Discord.

## Installation

1. Dans Home Assistant : Paramètres → Modules complémentaires → Boutique des modules complémentaires → ⋮ → Dépôts → ajoute `https://github.com/turak/EcoleDirectHA`.
2. Installe l'add-on **EcoleDirecte vers Discord**.
3. Suis les instructions dans l'onglet Documentation de l'add-on avant de le démarrer.
